Tatil önizlemesi, kayıtlı seyahat, destinasyon kataloğu ve scraper giriş uçları. HTTP sözleşmesi ayrıca /swagger-ui.html üzerindedir. Bu site Java kaynaklarındaki Javadoc yorumlarından üretilir.

Fikir ve sözleşme

Paket fikri kök package-info.java içindedir. controller, dto ve exception kendi özetini tutar. Sınıf ve metot sözleşmesi, türün hemen üstündeki yorumdadır.

Nasıl üretilir

api dizininde:

mvnw.cmd javadoc:javadoc

Çıktı api/target/reports/apidocs/index.html.
